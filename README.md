# Ian's Photography Portfolio

## Description

Ian's Photography Portfolio is a simple, responsive website built using HTML and CSS. The website showcases my favourite photographs, provides a short biography about myself, and includes a contact form where visitors can send messages.

The aim of this project is to demonstrate my understanding of HTML elements, CSS styling, page layout, responsive web design, and GitHub deployment.
